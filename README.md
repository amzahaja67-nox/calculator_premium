# Calculator App

Kalkulator berbasis web dengan tampilan responsif dan tema gelap. Aplikasi dibuat menggunakan HTML, CSS, dan JavaScript, tanpa proses instalasi atau server.

## Cara menggunakan

1. Unduh atau klon repositori ini.
2. Buka file `index.html` di browser.
3. Gunakan tombol angka dan operator (`+`, `−`, `×`, `÷`) untuk memasukkan perhitungan.
4. Tombol `C` menghapus input, sedangkan `⌫` menghapus satu karakter.

## Catatan

Saat ini, tombol `=` menampilkan pemberitahuan pembayaran; hasil perhitungan belum ditampilkan. Informasi pembayaran belum terhubung ke sistem transaksi atau verifikasi otomatis. Panel riwayat juga belum menyimpan hasil perhitungan.

## File utama

- `index.html` — struktur halaman.
- `style.css` — tampilan dan tata letak.
- `script.js` — interaksi kalkulator.
- `Image/` — gambar QRIS dan ikon situs.
